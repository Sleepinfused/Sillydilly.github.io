## the tech

- **markup:** HTML + CSS + vanilla JS
- **posts:** Markdown files (using [marked.js](https://marked.js.org))
- **hosting:** GitHub Pages (free!!)
- **fonts:** VT323 + Space Mono via Google Fonts
- **vibes:** early 2000s personal site energy

## how to add content

**posts:** add a `.md` file to the `/posts/` folder, then add it to the `posts` array in `js/config.js`

**photos:** add images to `/images/`, then add them to the `photos` array in `js/config.js`

**about/home:** edit `posts/about.md` or `posts/home.md`
